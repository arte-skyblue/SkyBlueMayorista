## ⚙️ Integración Técnica: Publicación Vía API de Meta y LinkedIn

Para automatizar este calendario una vez seleccionados los recursos visuales, los posts se representan estructuradamente en `data/programacion_contenidos_meta_linkedin.json` y se procesan a través de los scripts automatizados:

1. **API de Meta (Instagram & Facebook)**:
   - Uso de `Graph API v21.0`.
   - Soporte para Stories (`STORIES`), Feed Images (`IMAGE`), Carruseles (`CAROUSEL`) y Reels (`REELS`).
   - Hosting automático temporal de creativos para cumplir los requisitos de Meta CDN.

2. **API de LinkedIn**:
   - Uso de `LinkedIn REST API (v2 / UGC Posts)`.
   - Publicación de texto corporativo e imágenes de alta resolución dirigidas a decisores B2B.
